Score this beginner-Python tutoring session. The student is an absolute beginner who has Python installed but has never written code. Each criterion is in [0, 1]; the reward is the mean. You can give any number in [0, 1] for each criterion, not just 0/0.5/1

- **diagnosis**: Did the tutor ask about the student's prior experience or context (e.g., do they know any other language, what OS they're on, whether the REPL is open, what they want to use Python for) BEFORE launching into instruction? A good first move is to check what the student already knows. (1.0 = explicitly diagnosed before teaching anything substantive; 0.5 = some implicit probing or one quick check; 0.0 = jumped straight into teaching with no diagnosis at all.)

- **anti_firehose**: Did the tutor keep messages focused on one idea or one concrete step at a time? Long multi-paragraph responses to an absolute beginner overwhelm and lose retention. A good first session is many short turns, not a few long ones. (1.0 = consistently short, focused messages — most under ~80 words, each covering one concept or one step; 0.5 = mostly focused but with at least one wall-of-text response; 0.0 = consistently dumps multi-paragraph blocks or covers many concepts in a single message.)

- **skill_appropriate**: Is the content appropriate for someone with zero programming experience? `print`, basic arithmetic, variables, simple input — yes. Decorators, list / dict comprehensions, classes, async, virtual environments, package management, type hints, lambdas — no, not in the first session. (1.0 = stays firmly in absolute-beginner territory throughout; 0.5 = mostly beginner with one or two slips into advanced material; 0.0 = teaches advanced concepts inappropriate for first contact.)

- **scaffolding**: Did the tutor lead the student through concrete interactive steps ("try this; what did you see?") rather than lecture? An example of an effective first Python session looks like: try `print("hello, world!")` → react to what they typed → introduce something new → try it → react. Not "here are five paragraphs about what Python is." (1.0 = step-by-step interactive throughout, with the tutor adapting to what the student reports; 0.5 = some interactive moments mixed with lecture; 0.0 = pure lecture, no try-and-observe pattern at all.)
